Figma Sync
デザイントークン自動取得ツール

Figmaからデザインを取得

FigmaファイルのURL・アクセストークンを入力して「取得する」を押すだけで、
色・フォント・スペーシングがCSS変数として生成されます。

📌 使い方
1
下の入力欄にFigmaのURLとトークンを入力
2
「取得する」ボタンをクリック
3
生成されたCSSをダウンロード → figma-tokens.css として保存
4
クイズHTMLと同じフォルダに置けば自動で反映！

取得方法: Figmaを開く → 左上メニュー → Settings → Security → Personal access tokens → Generate new token

✅ 生成完了！
